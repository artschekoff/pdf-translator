PDF Translator is a Go CLI project that translates PDFs while preserving layout. It distinguishes native-text and scanned pages, extracts text with MuPDF/OCR, translates via OpenAI, and renders translated text back onto PDF pages. Core packages: internal/extractor, internal/recognizer, internal/translator, internal/renderer, internal/pipeline, internal/queue. Entry point: cmd/translator/main.go. Uses SQLite via GORM for resumable jobs.
