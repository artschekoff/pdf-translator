Useful commands:
- `make test` or `go test ./...` to run tests
- `go test ./internal/renderer` to run renderer tests
- `make build-mac` / `make run-mac ARGS="translate input.pdf --to spanish"` for macOS
- `make build-win` / `make run-win ARGS="translate input.pdf --to spanish"` for Windows
- `make lint`, `make fmt`, `make vet`, `make validate`
- Repo custom command from AGENTS.md: `test` prints "Hello from Codex"
